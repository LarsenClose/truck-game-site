# Truck: Dig & Drive - Web Version

Play online at: https://larsenclose.github.io/truck-game-site/

## About

Truck: Dig & Drive is a free, ad-free snake-style game with a unique dig mechanic. Navigate your truck, collect cargo, and compete on global leaderboards!

## Features

- 🆓 100% Free - No ads or purchases
- 🏆 Global leaderboards via Firebase
- 🎯 4 exciting game modes
- ⛏️ Unique dig mechanic
- 🎨 Retro pixel art style
- 📱 Cross-platform (iOS, Android, Web)

## Development

Built with Flutter and Firebase. The web version is automatically deployed to GitHub Pages.
